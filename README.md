# kamni

Лендинги ювелирного бренда (камни/украшения) — два варианта.

- `v1-vesara.html` — классический лендинг-витрина
- `v5-ruchnoe-myshlenie.html` — «Ручное мышление»: интерактивный 3D-конструктор браслетов/бус на Three.js (Bead Design Board) — набираешь украшение из бусин прямо в браузере

Фотографии товара — в корне (`photo_*.jpg`).

## Стек

HTML/CSS/JS + Three.js (для 3D-конструктора). Сборка не нужна — открыть HTML в браузере.
